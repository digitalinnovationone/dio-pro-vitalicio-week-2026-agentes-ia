Conceitos

Os 7 fundamentos para sua primeira semana

Cada card traz a ideia, uma descrição direta e uma dica prática para você aplicar agora mesmo.

  • 1

    CLAUDE.md

    Arquivo de memória do projeto que o Claude lê em toda sessão para entender o contexto global.

    Dica: registre stack, convenções de código e comandos frequentes.

  • 2

    Plan Mode

    Modo que mostra o plano detalhado antes de o Claude executar qualquer ação no sistema de arquivos.

    Dica: use sempre que a tarefa envolver múltiplos arquivos ou comandos sensíveis.

  • 3

    Slash Commands

    Atalhos para acionar fluxos de trabalho específicos com um único comando, como /review.

    Dica: salve seus templates recorrentes em .claude/commands/.

  • 4

    Skills

    Instruções reutilizáveis que o Claude segue automaticamente para padronizar ações de desenvolvimento.

    Dica: armazene em .claude/skills/ para padronizar tarefas repetitivas.

  • 5

    MCP (Model Context Protocol)

    Protocolo de padrão aberto que conecta o Claude a ferramentas externas, APIs e bancos de dados.

    Dica: comece integrando uma ferramenta que você já usa no dia a dia.

  • 6

    Context

    Gestão ativa do que o Claude está enxergando agora, incluindo arquivos selecionados, histórico da sessão e regras.

    Dica: mantenha o contexto enxuto, removendo o que não é mais relevante.

  • 7

    Compaction

    Compressão inteligente de conversas longas para economizar tokens sem perder informações essenciais.

    Dica: acione em sessões longas para manter o desempenho e o foco da IA.
